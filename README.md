# Эксперимент 4. Исполнение коммуникационного протокола

Проверяем, может ли Codex исполнить заданный полудуплексный протокол
для вычисления IP и DISJ. Сохраняем действия игроков, наблюдения
канала и итоговые ответы, затем считаем метрики по журналу.

## Результат пробного прогона

Для IP на трёхбитных входах проверены 18 разных пар.
Алиса играла по эталонному алгоритму на Python, Бобом управлял Codex.
В 18 из 18 игр оба дали правильный ответ и точно выполнили протокол.

## Как посмотреть результаты

1. Открыть `experiment4.ipynb` в Jupyter или VS Code.
2. Выполнить **Run All** с `run_mode = "off"`.
3. Для пересчёта метрик указать путь к исходному JSONL из `results/`
   в разделе 12. Для графиков указать путь к отчёту `_analysis_`
   в разделе 13. Для построения графиков нужен `matplotlib`.

В `results/` лежат исходный журнал и отчёт с метриками.
Для просмотра и пересчёта сохранённых результатов Codex не нужен.

## Как запустить новый эксперимент

Установить Codex CLI, войти через `codex login` и в разделе 11
выставить `run_mode = "episode"`, `backend = "cli"` и
`players = "python-codex"`. Параметр `case_limit` задаёт число
входных пар, `repeats` — число игр на каждой паре.
